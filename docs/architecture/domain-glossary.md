# Domain Glossary

| Term | Meaning |
| --- | --- |
| Employee | End user who consumes assigned courses and tracks personal progress. |
| Manager | Operational leader who can observe learning progress within an allowed management scope. |
| HR | Business operator who assigns learning programs and monitors completion across departments. |
| Admin | Platform operator who manages learning content and operational settings. |
| Super Admin | Highest internal role with platform-wide control over security, configuration, and audit access. |
| Department | Organizational unit used for assignment targeting and reporting scope. |
| Course | Top-level learning product assigned to users, departments, or role-based audiences. |
| Module | Structural unit inside a course that groups lessons. |
| Lesson | Concrete learning unit containing content and optional progress checkpoints. |
| Lesson Content | Typed educational payload such as text, video, file, or checklist. |
| Test | Assessment attached to a course or lesson. |
| Question | Single assessment item inside a test. |
| Answer Option | Selectable answer variant for a question. |
| Assignment | Targeted distribution of a course to a user, department, or role scope. |
| User Progress | Current user state for a course, module, or lesson. |
| Completion Record | Immutable record that confirms a user completed or failed a learning milestone. |
| Quiz Attempt | Submitted test session with answers, score, and status. |
| Progress Event | Append-only event that captures meaningful learning activity. |
| Notification | User-facing message about assignments, reminders, deadlines, or outcomes. |
| Admin Audit Log | Immutable administrative activity trail for write operations and security-sensitive actions. |
| File Asset | Stored file metadata with secure access policy and ownership context. |
| Course Version | Versioned snapshot of course structure for publishing, reporting, and historical integrity. |
