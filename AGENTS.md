# AGENTS.md — annaelleapple

## Что это
Каркас монорепозитория внутренней LMS ANNAELLE (Flutter-мобильное приложение, NestJS-сервер, Next.js-админка — планируемый стек). Сейчас — только документы, контракты и соглашения. См. `README.md`, `conventions.md`.

## Где работает
Нигде: не выпущен, серверов и боевых данных нет.

## Ветки и выпуск
Единственная ветка `main` (она же по умолчанию). Правки — веткой `claude/<тема>-<дата>`/`codex/…` и PR; в `main` напрямую не писать. «Выпуска» нет.

## Чего нельзя
- **Репозиторий публичный.** Нельзя коммитить ключи, токены, `.env` (только `.env.example` без значений), адреса боевых серверов, данные клиентов и сотрудников, внутренние решения владельца.
- Не придумывать стек и функции без требований; сначала контракты, потом реализация (см. `conventions.md`).
- Не менять видимость репозитория, не делать force-push, не удалять ветки — только владелец.

## Где журнал
`README.md` → «История изменений» (новое сверху: дата, что изменилось, PR); дописывать в том же ходе, что любое изменение.
